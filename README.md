# Project: Dataset Visualization

## Overview

This project is an interactive data visualization application built with Python, Dash and Plotly. It explores video game sales data to answer questions about platforms, genres, publishers, release years and regional sales.

The application uses Pandas and NumPy for data processing, Plotly Express for visualizations, Dash for the interactive web application and Dash Bootstrap Components for layout and styling.

## Requirements

- Miniconda or Anaconda
- Python 3.12
- A terminal, such as PowerShell or the VS Code terminal

## Project Structure

```text
project/
├── app.py
├── DataPreparation.py
├── data/
│   ├── preparedData/
│   └── ...
├── pages/
│   └── ...
├── assets/
│   └── ...
├── reports/
│   └── ...
└── README.md
```


- `app.py` – starts the Dash application.
- `DataPreparation.py` – processes the source data and creates the DataFrames required by the application.
- `data/` – contains the source datasets.
- `data/preparedData/` – stores the prepared data files generated by `DataPreparation.py`. These files are used by the Dash application.
- `pages/` – contains the application pages.
- `assets/` – contains the css file used by the application.
- `reports/` – contains project documentation.

## 1. Create a Python Virtual Environment

Open a terminal in the project root directory and create a Conda environment using Python 3.12:

```powershell
conda create -y -p ./.conda python=3.12
conda activate ./.conda
```

If the environment already exists, activate it instead of creating it again:

```powershell
conda activate ./.conda
```

## 2. Install Required Packages

With the environment activated, install the packages used by the project:

```powershell
python -m pip install numpy pandas plotly dash dash-bootstrap-components
```

These packages provide the functionality needed for data processing, interactive visualizations and the Dash application.

## 3. Prepare the Data

**This step must be completed before starting the Dash application.**

Run `DataPreparation.py` from the project root directory:

```powershell
python DataPreparation.py
```

The script processes the source data and creates the prepared DataFrames required by the application. The resulting files are saved in:

```text
data/preparedData/
```


## 4. Run the Dash Application

After the data preparation has completed successfully, start the Dash application:

```powershell
python app.py
```

Open the local URL displayed in the terminal. It is usually:

http://127.0.0.1:8050/


To stop the application, press `Ctrl+C` in the terminal.

## 5. Running the Project from Scratch

To set up and run the project on a new computer, follow these steps in order:

1. Install Miniconda or Anaconda.
2. Open a terminal in the project root directory.
3. Create and activate the Conda environment.
4. Install the required Python packages.
5. Run `DataPreparation.py` to generate the prepared data files.
6. Run `app.py` to start the Dash application.
7. Open the local URL displayed in the terminal.
